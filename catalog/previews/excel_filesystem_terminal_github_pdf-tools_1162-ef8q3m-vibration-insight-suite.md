# Vibration Insight Suite

General-purpose vibration analytics platform: multi-station acquisition,
dashboards, alerting rules and long-term archiving.

Topics: adaptive-duty-cycle-sampling, vibration, condition-monitoring, time-series

Implements: none | framework only

Adaptive duty-cycle sampling appears here as a supported acquisition plug-in
category: the SDK exposes hooks so integrators can supply their own duty-cycle
scheduler. The suite ships no implementation of any published schedule and is
not tied to a particular memo.
