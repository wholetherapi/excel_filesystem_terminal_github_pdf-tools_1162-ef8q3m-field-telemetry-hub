# Calder Ridge field telemetry hub

Working records for the vibration-logger field programme (memo CRI-TM-2087).

- `data/field_export_2021_2026.csv` - reconciled monthly export. Wide layout with two
  header rows (site group on row 1, metric on row 2) and a staging block per site.
- `catalog/candidates.csv` - public projects tracked by the observatory.
- `catalog/keyword_monitor.json` - saved keyword-monitor output for the query
  "adaptive duty-cycle sampling".
- `catalog/previews/` - mirrored README snapshots of the tracked projects.
- `registry/verified_ports.json` - independent reproductions adopted by the field team.
