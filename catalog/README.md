# Candidate catalogue

`candidates.csv` lists the public projects surfaced by the observatory while
tracking adaptive duty-cycle sampling work. `stars_snapshot` and
`forks_snapshot` are periodic captures of the projects' primary hosting pages;
snapshots can lag the live pages.

`previews/<project>.md` holds the observatory's mirrored README snapshot for each
tracked project; it is the review copy used when the upstream page is unreachable.

`keyword_monitor.json` is the saved relevance-ordered output of the keyword
monitor for the query "adaptive duty-cycle sampling".
